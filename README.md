# Café Serrano - Sistema Web SOA

Proyecto de arquitectura orientada a servicios para una cafetería.

## Requisitos
* Docker y Docker Compose
* Git

## Instalación y Ejecución
1. Clona el repositorio: `git clone https://github.com/TU_USUARIO/cafe-serrano-soa.git`
2. Entra a la carpeta: `cd cafe-serrano-soa`
3. Copia el archivo de ejemplo: `cp conexion.example.php conexion.php` y configura tus credenciales.
4. Levanta los servicios con Docker: `docker-compose up -d`
5. Abre en tu navegador: `http://localhost:8080`

## Tecnologías
* HTML, CSS, JavaScript
* PHP
* MySQL
